# Screenshot gallery

- Desktop viewport: 1440 × 1000 px, with full-page captures where needed.
- Mobile viewport: 390 × 844 px, with full-page captures where needed.

The preview used the project's page components and styles. Authentication and interview data were replaced only in an isolated temporary copy. Cover selection was fixed for reproducible screenshots.

These images document the interface, not successful connections to Firebase, Gemini, or Vapi. The production application's authentication and service configuration were not changed for capture.

To refresh the gallery, capture the corresponding routes from a configured local app using a dedicated demo account, or an isolated copy with sample data. Keep personal information and credentials out of screenshots. Review each image and use the same filenames to preserve the README links.
